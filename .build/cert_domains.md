# Certification Domain Reference (verified from infosecinstitute.com, June 2026)

## CISSP (ISC2) — 8 domains (exam effective May 2021)
1. Security and Risk Management (15%): ethics, security concepts (CIA, AAA), governance, compliance, legal/regulatory, investigation types, policies/standards/procedures, BC requirements, personnel security, risk management, threat modeling, supply chain risk management (SCRM), security awareness/education/training.
2. Asset Security (10%): identify/classify info & assets, handling requirements, secure provisioning, data lifecycle, asset retention (EOL/EOS), data security controls & compliance (DRM, CASB, DLP).
3. Security Architecture and Engineering (13%): secure design principles (threat modeling, defense in depth, least privilege, fail securely, secure defaults, separation of duties, zero trust, privacy by design), security models, control selection, IS security capabilities, vulnerability mitigation, cryptographic solutions, cryptanalytic attacks, site/facility security design.
4. Communication and Network Security (13%): secure network architecture (segmentation, micro-segmentation, wireless, CDN), secure network components, secure communication channels, IPSec/IPv4/IPv6.
5. Identity and Access Management (IAM) (13%): physical/logical access control, identification/authentication (SSO, JIT), federated identity, authorization mechanisms, identity provisioning lifecycle, authentication systems.
6. Security Assessment and Testing (12%): assessment/test/audit strategies, security control testing, security process data, test output analysis/reporting, security audits.
7. Security Operations (13%): investigations, logging/monitoring, configuration management, foundational SecOps, resource protection, incident management, detective/preventive measures, patch/vuln management, change management, recovery strategies, DR, DRP testing, BC planning, physical security, personnel safety.
8. Software Development Security (11%): security in SDLC, controls in dev ecosystems (CI/CD, SAST/DAST), software security effectiveness, acquired software impact, secure coding guidelines.

## CompTIA Security+ SY0-701 — 5 domains
1. General Security Concepts: control types/categories, CIA triad, security terminology, change management, cryptographic solutions.
2. Threats, Vulnerabilities & Mitigations: attack vectors (social engineering, malware, phishing, DoS, zero-day), vulnerability management, indicators of malicious activity, mitigation techniques.
3. Security Architecture: architecture models, secure network design (segmentation, DMZ), data protection/classification, resiliency & recovery, access control.
4. Security Operations: monitoring & logging, security automation & orchestration (SOAR), SIEM, identity & access management, hardening.
5. Security Program Management & Oversight: policies & standards, compliance (HIPAA, PCI DSS), risk management frameworks (NIST CSF), security awareness & training, GRC reporting/communication.

## CEH v13 (EC-Council) — 9 domains
1. Information Security & Ethical Hacking Overview (6%): IS concepts, cyber kill chain, controls/standards, terminology, legal frameworks.
2. Reconnaissance Techniques (17%): footprinting & reconnaissance, scanning networks, enumeration (NetBIOS, SMB, SNMP, LDAP, NTP, NFS, SMTP, DNS).
3. System Hacking Phases & Attack Techniques (15%): vulnerability analysis, system hacking (password attacks), malware threats (trojans, RATs, analysis).
4. Network & Perimeter Hacking (24%): sniffing, social engineering, DoS/DDoS, session hijacking, evading IDS/firewalls/honeypots.
5. Web Application Hacking (14%): hacking web servers, hacking web applications, SQL injection.
6. Wireless Network Hacking (5%): wireless concepts, encryption weaknesses, attacks, methodology, tools, Bluetooth.
7. Mobile Platform, IoT & OT Hacking (10%): mobile (Android/iOS, OWASP Mobile Top 10), IoT and OT hacking.
8. Cloud Computing (5%): service/deployment models, containers, serverless, cloud threats, shared responsibility.
9. Cryptography (5%): symmetric/asymmetric, algorithms, PKI, digital signatures, cryptanalysis, tools.

## CISA (ISACA) — 5 domains (Aug 2024 weights)
1. Information Systems Auditing Process (18%): IS audit standards/frameworks (COBIT), risk assessment methodologies, audit planning/execution/reporting, evidence collection/analysis, internal controls evaluation, IT compliance (GDPR, CCPA).
2. Governance and Management of IT (18%): governance frameworks (COSO, COBIT), risk management (ERM, BCM), IT policy/procedure, resource allocation, BCP/DR, performance/KPIs, IT service management.
3. Information Systems Acquisition, Development & Implementation (12%): procurement/vendor selection, project management (Agile, Waterfall), secure coding/vuln mgmt, SDLC, change/configuration management, testing.
4. Information Systems Operations & Business Resilience (26%): ITIL, security operations & incident response, BCP/DR, monitoring/performance, access control, backup/recovery.
5. Protection of Information Assets (26%): data security, access control & identity management, encryption & DLP, security incident management & forensics, privacy & security laws, BYOD/cloud security.

## CGRC / CAP (ISC2) — 7 job practice areas (RMF-aligned)
1. Information Security Risk Management Program (16%).
2. Scope of the Information System (11%).
3. Selection and Approval of Security and Privacy Controls (15%).
4. Implementation of Security and Privacy Controls (16%).
5. Assessment/Audit of Security and Privacy Controls (16%).
6. Authorization/Approval of Information System (10%).
7. Continuous Monitoring (16%).
