# Diagram sources

The `.drawio` sources here have been converted to native Mermaid diagrams embedded directly in the chapters,
for consistency with the rest of the book and for accessibility (they render as structured markup, not flat
images):

- `core_terms_concept_map.drawio` -> Chapter 1, "A Concept Map of the Core Terms" (Mermaid).
- `four_transformations.drawio` -> Chapter 2, "Four Transformations Compared" (Mermaid).

The original `.drawio` files are retained as editable sources.
